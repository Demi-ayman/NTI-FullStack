# 🛒 E-Commerce Cart & Order Management System

A modern **Angular-based Shopping Cart and Order Management module** integrated with a Node.js + Express backend and MongoDB.  
This system allows users to **browse products, add to cart, manage quantities, place orders**, and view order history seamlessly.

---

## 🚀 Features

✅ **Add to Cart / Remove from Cart**  
✅ **Update product quantities dynamically**  
✅ **Sync with authenticated backend cart**  
✅ **Checkout with server-side order creation**  
✅ **Responsive and clean UI using modern CSS**  
✅ **Fallback to LocalStorage for guest users**  
✅ **Error handling for image loading and APIs**  
✅ **Integration with Auth system (login/register)**  

---

## 🧱 Tech Stack

| Layer | Technology |
|-------|-------------|
| **Frontend** | Angular 17+, TypeScript |
| **Backend** | Node.js, Express.js |
| **Database** | MongoDB (Mongoose) |
| **Authentication** | JWT-based auth |
| **Styling** | Pure CSS / Tailwind (optional) |
| **API Integration** | HttpClientModule |
